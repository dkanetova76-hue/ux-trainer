ПРАВКИ ДЛЯ teacher.html — подключение курса «UX-менеджмент и цифровой опыт» (ключ ux)
=====================================================================================
Откройте актуальный teacher.html из репозитория isu-trainer и внесите 4 правки.

1) В объект COURSES добавьте строку (не забудьте запятую у предыдущей):
  ux: {name:'UX-менеджмент и цифровой опыт', short:'UX', book:'https://dkanetova76-hue.github.io/ux-trainer/'}

2) Рядом с ISU_LEC / KU_LEC добавьте списки названий:
const UX_LEC = ['UX-менеджмент и качество цифрового сервиса','Постановка UX-проблемы','Дизайн UX-исследования','Качественные и количественные данные в UX-исследовании','Пользовательский путь и схема предоставления сервиса','Проектирование пользовательского потока','Юзабилити-тестирование цифрового сервиса','Цифровая доступность','UX-метрики и оценка эффекта','Приоритизация и внедрение UX-изменений'];
const UX_PR = ['Диагностика цифрового сервиса','Постановка UX-задачи','План UX-исследования','Пилотирование инструмента','Анализ наблюдений','Карта пользовательского пути','Проектирование альтернатив','Создание кликабельного прототипа','Эвристическая оценка интерфейса','Юзабилити-тестирование прототипа','Проверка цифровой доступности','Расчёт UX-метрик','Приоритизация UX-улучшений','Защита управленческого решения'];
const UX_SRM = ['Сравнение сервисов','Уточнение проблемы','Обзор литературы','Пилотный сбор','Анализ и карта пути','Доработка прототипа','Юзабилити и доступность','Журнал решений','План измерения','Итоговый отчёт'];

3) В объект CC добавьте ключ ux:
  ux: {LEC: UX_LEC, PRACT: UX_PR.length, prLabel:'Практики',
    TESTS: [...UX_LEC.map((n, i) => ['L' + (i + 1), `Лекция ${i + 1}. ${n}`, 'Л' + (i + 1)]),
            ...UX_PR.map((n, i) => ['P' + (i + 1), `П${i + 1}. ${n}`, 'П' + (i + 1)]),
            ...UX_SRM.map((n, i) => ['S' + (i + 1), `СРМ-${i + 1}. ${n}`, 'С' + (i + 1)]),
            ['DX', 'Диагностический вариант', 'Диагн.']],
    REPS: UX_PR.map((n, i) => ['PR' + (i + 1), `П${i + 1}. ${n}`, 'П' + (i + 1)])}

4) В <head> рядом с другими plan.js добавьте:
<script src="https://dkanetova76-hue.github.io/ux-trainer/plan.js"></script>

После этого в кабинете (вкладка «Группы») переключитесь на «UX» и создайте группу ИТМм-1-26 — код этой группы дадите магистрантам.
В базе ничего менять не нужно: поле groups.course уже есть (course-column.sql), таблицы те же.
