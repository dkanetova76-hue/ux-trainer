Электронный учебник «UX-менеджмент и цифровой опыт» (ключ курса: ux)

Файлы
  index.html        — учебник
  content.js        — лекции, практики, СРМ, контроль (из УМК)
  tests.js          — 240 тестов + 8 открытых заданий
  local.js          — хранение записей в браузере (если студент не вошёл)
  cloud.js          — вход по коду группы, учёт активности, сдача тестов и отчётов, синхронизация записей
  cloud-config.js   — адрес и публичный ключ общей базы Supabase (тот же, что у isu-trainer)
  plan.js           — план семестра для кабинета преподавателя
  teacher-patch-ux.txt — 4 правки для teacher.html, чтобы курс «UX» появился в кабинете

Запуск на GitHub Pages
  1. Создайте публичный репозиторий ux-trainer, загрузите в корень все файлы выше (кроме teacher-patch-ux.txt и README.txt).
  2. Settings → Pages → Deploy from a branch → main / root.
  3. Внесите правки из teacher-patch-ux.txt в teacher.html репозитория isu-trainer.
  4. В кабинете преподавателя переключитесь на «UX» и создайте группу ИТМм-1-26 — код группы дайте магистрантам.

В базе ничего менять не нужно: используются те же таблицы (profiles, groups, events, submissions, drafts) и хранилище works.
Все записи этого курса помечаются data.course = 'ux'.
Дата начала семестра в plan.js — предположение (2027-02-08), поправьте при необходимости.
Если в папке остался файл progress.js от предыдущей версии — он не нужен (его заменил local.js).
